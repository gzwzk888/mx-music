# MX Music · 墨玄音乐

面向**本地音乐库 + NAS 曲库**的 Android 音乐播放器。三栏横屏布局、11 段原生均衡器、完整歌词系统，支持简体中文 / 繁體中文 / English 三语界面。

> 本项目为个人定制版，与任何线上音乐平台无关，不提供在线曲库、不抓取第三方内容。你播放的每一首歌，都是你自己的文件。

**界面与交互为全新设计**：三栏横屏结构、大图网格曲库、卡片三行信息（歌名 / 艺术家·专辑 / 来源）、
均衡器面板、桌面歌词悬浮窗、平板与手机的响应式布局，均为本项目自行设计实现，
与任何第三方播放器的界面不存在继承关系。

## 主要功能

### 音乐库

- **本机曲库**：扫描你指定的文件夹，支持 WAV / FLAC / APE / MP3 / M4A / OGG 等常见格式，内嵌封面优先读取
- **NAS 曲库**：DLNA 发现与浏览、目录翻页、地址记忆；SMB / HTTP 直连播放
- **两种视图**：大图网格（手机 3 列 / 平板 4 列）与列表，一键切换
- **分组浏览**：按歌曲、专辑、艺人、文件夹；支持按「全部 / 本机 / NAS」筛选
- **搜索**：歌名、艺人、专辑、文件夹路径全文匹配

### 播放

- 三栏横屏布局：左侧封面与控制、右侧常驻歌词，平板自动展开宽侧栏
- 睡眠定时（15 / 30 / 60 / 90 分钟或播完当前曲目）
- 上/下一首、循环、随机、单曲循环
- 托盘常驻播放控制，播放键与进度条跟随主题色

### 11 段均衡器（原生 DSP）

- 频点：31.5 / 63 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k / 32k Hz，每段 ±12 dB
- 独立预增益，防止削波
- **常用预设 10 个**：平坦、原声、古典、深沉、爵士、流行、节奏蓝调、小音箱、高音增强、人声增强
- **特色艺人预设 8 位**：蔡琴、童丽、赵鹏、Scott Ian、Leo Nocentelli、Tim Lopez、Buckcherry、Strange Talk
- 真正挂在音频处理链上（不是界面假调），本机与 NAS、WAV 与 FLAC 全部生效
- 设置重启后保留

### 歌词

- 内嵌歌词（ID3 / Vorbis / APE）与同名 `.lrc` 自动匹配
- 在线搜索：酷狗 / QQ 音乐 / LRCLIB，多源兜底
- 歌词同步：±0.5 秒微调，按曲目单独保存
- 当前行高亮跟随主题色；支持字号三档、对齐三档（竖屏与横屏分别记忆）
- **桌面歌词**：悬浮窗显示，6 种配色（蓝 / 黄 / 橙红 / 绿 / 黑 / 白），支持锁屏悬浮

### 界面

- 主题强调色：蓝（默认） / 黄 / 橙红，切换后全局立即生效
- 深色界面，无第三方品牌痕迹
- 简体中文 / 繁體中文 / English 三语，首启即可选择，随时可在设置中更改
- 列表卡片右上角 `⋯` 菜单：播放、打开所在文件夹、加入我的最爱、加入播放列表

## 首次启动

1. 选择语言（简 / 繁 / 英）
2. 阅读并接受许可协议
3. 阅读防骗提示
4. 进入首页 → 到「本机曲库」添加你的音乐文件夹，或到「NAS 曲库」连接你的 NAS

## 从源码构建

环境要求：Node.js 20+、JDK 17/21、Android SDK（platform 36 / build-tools 36 / NDK 26.1）、Gradle 8.8。

```bash
npm install
cd android && ./gradlew assembleRelease
```

产物位于 `android/app/build/outputs/apk/release/`。

签名使用自签 keystore，配置见 `android/keystore.properties`（该文件与 keystore 不入库）。
